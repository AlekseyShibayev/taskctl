# SPEC — taskctl

## `create(text)`

| Поле | Тип | Обяз. | Правило |
|------|-----|-------|---------|
| `text` | string | да | непустой, ≤ 2000 символов, валидный UTF-8 |

- Пустой или из одних пробелов → ошибка `isError`, текст `text must not be empty`.
- Длиннее 2000 символов → `isError`, `text must be at most 2000 characters`.
- Лимит считается в символах (рунах), не в байтах: 2000 символов ≈ экран 80×25.
- Невалидный UTF-8 → `isError`.
- Неизвестные поля в аргументах → `isError`, а не игнор.
- Исключений в MCP нет: ошибка хендлера отдаётся клиенту как результат с `isError: true`, текст — в `content[0].text`.
